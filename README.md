# 🎮 موقع زخرفة أساطير الألعاب (Gamer Nickname Decorator)

موقع ويب تفاعلي حديث وسريع جداً لزخرفة أسماء أشهر الألعاب (ببجي موبايل PUBG، فري فاير Free Fire، كول أوف ديوتي COD، وغيرها) بتصميم Dark Gaming احترافي وتجربة مستخدم سلسة.

---

## ✨ المميزات الرئيسية

1. **زخرفة فورية أثناء الكتابة (Live Generation):**
   - يدعم اللغتين العربية والإنجليزية.
   - تشكيلات عربية فخمة (مدات، حركات، تشكيل متقن، حروف نادرة).
   - أكثر من 8 خطوط إنجليزية بنظام Unicode (Gothic, Cursive, Double-Struck, Small Caps, Bubbles, Monospace, وغيرها).

2. **رموز وإطارات أساطير مقبولة في الألعاب:**
   - شارات ببجي المعتمدة: `꧁༺ ༻꧂`, `亗 『 』 亗`, `〆`, `彡`, `☬`, `༒`.
   - شارات فري فاير المحبوبة: `×͜×`, `𓆩 𓆪`, `OP ᭄`, ``, `⚡`.

3. **أداة نسخ المسافة المخفية (Invisible Space):**
   - نسخ بنقرة واحدة لرمز المسافة المخفية (`Hangul Filler U+3164`) لعمل أسماء فارغة أو متباعدة في فري فاير وببجي بدون مشاكل.

4. **فاحص طول الاسم والحدود القصوى:**
   - عداد حروف ذكي ينبهك إذا تجاوز الاسم 14 حرفاً (حد ببجي) أو 12 حرفاً (حد فري فاير).

5. **استوديو الرموز النادرة (Symbols Studio):**
   - مكتبة أسلحة وسيوف، أجنحة، تيجان ورتب ملوك، نجوم وكواكب، قلوب وزهور، كوجي ورموز آسيوية.
   - النقر على أي رمز يضيفه فوراً لمكان المؤشر في الاسم.

6. **المفضلة والمؤثرات الصوتية:**
   - حفظ الأسماء المفضلة في المتصفح (`LocalStorage`).
   - مؤثرات صوتية جيمينج Synth تفاعلية بنقرة زر (يمكن كتمها أو تشغيلها).
   - إشعار منبثق (Toast) عند النسخ.
